# Method review (method2): paper against code and outputs

## Summary

I read the paper side by side with `init_shipping_zone_rev1.m`, the Hawaii, Alaska and PR/USVI init files, `shipping_zone_rev1.m`, `ais_cells_py_rev1.py` and their helpers. I compared each stated parameter with the code and each stated count with the files in `outputs/2024_2025`, `outputs/2018_2019` and `data/`. Most parameters and counts match: ship types, 100 m, IMO rule, 4/2-ship thresholds, 25 km tug-barge and shore-link distances, 73 deep-draft ports, band table, grid limits, and Tables 2, 4, 5 and 6. I found 22 problems. The most serious are these:

- The cached NOAA fairway file holds 28 features. The live service returns 291 for the same query. The cached file has no "Shipping Fairways" features at all, so the fairway line in Table 3 does not reflect what the paper says it does.
- The water-plus-land zone files extend over water that is far more than 25 km from any route.
- The land distance is measured from a coastline that sits up to 25 km from the routes, and the paper does not say so.
- The port-approach rule extends the Mississippi route about 30 km above the 4-ship cells.
- Table 5 mislabels two ports.
- Several counts (Puerto Rico 50 km, 166,382 pairs, 15 inland ports) are not supported by the current outputs.

Scratch work is in `/tmp/agent_scratch/method2/`. I changed nothing in the repo except this file.

## Checked and found correct

- Ship types in code and paper agree (`[0 33 35 55 60:89 90:99]`, towing `[31 32 52]`; military 35 and law enforcement 55 kept without IMO). The Alaska cache file name shows 44 types, as expected.
- Length 100 m, IMO test (non-empty string in both MATLAB and Python), grid 22–50° N and 66–130° W, 0.01° cells.
- Sampled days: the first 52 Wednesdays (2024-01-03 to 2024-12-25; 2025-01-01 to 2025-12-24), 104 days. Alaska uses 2018-01-03 and 2019-01-02 starts.
- Ship-per-cell rule: distinct MMSI per calendar year, union of years, threshold 4. I recomputed the non-towing 4-ship cells from the day caches: 649,737, equal to A.5's "649,737 cells from the other large ships".
- Port-approach rule: 2 ships, 50 km, foreign trade of 1 million tons or more and type not "I"; 73 ports (63 coastal, 10 Great Lakes); 15,782 cells in the run log. Total 658,865 + 15,782 + 1,099 + 17 = 675,763.
- Tug-barge rule: 25 km from the Census coastline; the coastline file does include the Great Lakes (vertices near Cleveland and Duluth) and bays. Without the coastal limit, 684,212 cells meet the threshold against 649,737 for the main filter.
- Table 1, Table 2 totals (1,980 and 1,886), Table 4 (all 15 rows), Table 5 (all 73 rows, apart from the column label in method2-6), Table 6 (all 15 rows; 10 of 15 below 50%), Table 7 file names, Table 8 counts.
- Shore-link 25 km, zone distances 25/50/100 km, band table, simplification 0.005° (about 0.5 km), nested zones.
- The Census coastline layer does not cover the Mississippi above New Orleans, and also not Philadelphia, Albany, Portland OR or Sacramento.
- Hawaii: ship-days cutoff 6, 7,310 cells, port-approach rule off, ports reached and distances (Hilo 5.0, Kawaihae 24.8 km), land areas in the run log, no NOAA fairway themes in the grid (only "Area to be Avoided" and a PSSA).
