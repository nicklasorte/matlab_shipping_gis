# Link check: data sources register and paper under review

Retrieved: 2026-11-12

This check covers 29 unique links: the 15 rows of the `link` column in `docs/plans/data_sources_register.csv` (14 unique URLs) and every http(s) link in `docs/review/paper_under_review.md` (17 unique URLs, 2 shared with the register). No link was confirmed broken. Two links have changed. First, `https://marinecadastre.gov/ais` (register row 1 and paper Sections 1.2 and A.21) no longer serves a page; it returns a 302 redirect to `https://hub.marinecadastre.gov/pages/vesseltraffic`, which the session couldn't fetch, so the years offered there weren't confirmed. Second, the PacIOOS ship traffic page (register row 9) doesn't match the register: it gives Hawaii data for 2008-2009 only at 1 km, the 2011-2012 period is a global 10 km product, and it names the U.S. Coast Guard Navigation Center, not PacIOOS, as the Hawaii data source. A third item is a wording check, not a changed link: the Army article in paper Section 1.3 confirms the June 10, 2024, full restoration, but it gives March 26, 2024, as the start of salvage work rather than stating a channel closure date. The session's fetch allowlist or a rate limit blocked 16 links, so their status is unknown, not broken. They're marked **Not checked** in the table and need a manual check in a browser.

## Method

Each link was requested once with the session's web fetch tool on 2026-11-12. A link counts as *loads* when the fetch returned page content. *Not checked* means the session's allowlist refused the fetch or the site rate-limited it; it says nothing about whether the link works. For link 1, the redirect target was also requested and refused. A web search found indirect evidence for links 1 and 21, noted in the table; search results don't count as a successful load.
